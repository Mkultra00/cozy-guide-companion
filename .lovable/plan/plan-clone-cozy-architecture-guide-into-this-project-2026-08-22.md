## What the repo is

is a **Lovable TanStack Start project on the same template base as this one**. Verified:

- Its `package.json` is byte-identical to this project's (same deps, incl. recharts, date-fns,

The app is a **read-only mission-control console** for a space-agriculture planning agent. It
renders a fixture snapshot (no backend) and would optionally read a local agent HTTP API via
`VITE_ASTROFARM_API`. Pages: `/` Console, `/plans` + `/plans/$version` history, `/library` crops,
`/brief` positioning. Custom dark theme (Space Grotesk + JetBrains Mono via `<link>` in root).
